SpendLens · iOS design system

Photograph the receipt.
Everything else is done.

Assumptions. Light mode first (dark follows the same token map). iPhone 15/16 class, 402×874. System type (SF Pro) with tabular numerals for every amount. Currency MDL, written after the number.
Direction. Warm paper white ground, ink-black primary action, one teal accent reserved for "the system understood this" (detection, confidence, category Food). Amber only for "check this". No red for spending — spending is information, not failure.
Screens below: Home, Review, Analytics, then the scanner in its four states. The review screen is interactive: tap the flagged item, switch category.
